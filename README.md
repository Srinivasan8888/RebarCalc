# RebarCalc

Web version of AutoScan Steel: turns a reinforcement schedule or an issued Bar Bending Schedule (BBS) workbook into an exact, editable BBS for RCC slabs and beams, and writes it back in the customer's Excel layout.

```
npm install
npm run dev      # http://localhost:5173
npm test         # vitest, the workbooks in data/ are the spec
npm run build    # tsc -b + vite
```

## What it does

- **Component mode**: members (slab panels, beams) with bar rows in the BBS column order. Every formula is a port of a cell in a real workbook and is locked by a test against that workbook's cached values.
- **Import**: a slab BBS (Provident layout), a beam BBS (DRA layout), or a beam *schedule* (rows generated by the DRA house rules, with a list of doubts to settle before cutting).
- **Export**: writes both layouts back with live formulas; export → import round-trips both reference workbooks.
- **Manual mode**: legacy shape-code entry (S1–S6) with CSV import and Excel export.
